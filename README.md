# PhysLab — Физикийн тоглоомжуулсан сургалт (7–12-р анги)

900.mn-ээс санаа авсан, зөвхөн **Физик** хичээлтэй сургалтын сайт.

## Ажиллуулах
`run.cmd` дээр давхар дарна (эхний удаа `.venv` үүсгээд сан суулгана) → http://127.0.0.1:47650
Админ: http://127.0.0.1:47650/admin — нэвтрэх мэйл/нууц үг `.env` доторх `ADMIN_EMAIL` / `ADMIN_PASSWORD`.
LAN-д нээх бол `.env`-д `HOST=0.0.0.0`.

- Гарын авлага: сайт дээр **📖 Тусламж** (`/#/guide`) — эх файл `static/guide.md`
- Git болон Vercel-д байршуулах заавар: [DEPLOY.md](DEPLOY.md) (Vercel дээр Postgres, локалд SQLite)

## Сурагчийн урсгал
1. Мэйлээр бүртгүүлнэ (нэр, анги 7–12, аватар).
2. **Түвшин тогтоох шалгалт** — түвшин бүрээс `PLACEMENT_PER_LEVEL` асуулт санамсаргүй. Доороос эхлэн дараалан тэнцсэн хамгийн өндөр түвшинд байрлана.
3. Газрын зураг (гариг) → **Онол** (YouTube + томьёо + quiz) → **Бодлого** (3 амь, таймер, combo, XP) → **Туршилт** (виртуал лаб + даалгавар).
4. Бүх хичээл ≥1 од → **Түвшний шалгалт** → тэнцвэл дараагийн түвшин нээгдэнэ.
5. XP, од, streak, badge, тэргүүлэгчид (ангиар).

Од: 50%+ ★, 70%+ ★★, 90%+ ★★★. XP зөвхөн рекорд ахихад нэмэгдэнэ (давтаж тоглоод XP «фарм» хийх боломжгүй).

## Хэрэглэгч нэмэх, харагдах хичээл (Админ → Сурагчид)
- **＋ Хэрэглэгч нэмэх**: нэр, мэйл (нэвтрэх нэр), нууц үг, анги, эрх, эхлэх түвшин.
  Эхлэх түвшин сонговол түвшин тогтоох шалгалтгүйгээр шууд тэндээс эхэлнэ.
- **Харагдах хичээлүүд**: «Бүх хичээл» эсвэл «Зөвхөн сонгосон хичээлүүд». Түвшний checkbox тухайн түвшний бүх хичээлийг сонгоно.
  Сонгоогүй хичээл, түвшин сурагчид огт харагдахгүй (хаягаар нь ороход ч 404).
- Одоо байгаа сурагчийн эрхийг «Дэлгэрэнгүй» дотроос өөрчилнө. Өөрөө бүртгүүлсэн сурагч «Бүх хичээл» горимтой.
- Хожим нэмсэн шинэ хичээл «сонгосон» горимтой сурагчид автоматаар харагдахгүй.

## Excel импорт (Админ → Excel импорт)
Template-ээ татаж бөглөнө. Sheet-үүд:
| Sheet | Баганууд |
|---|---|
| Шалгалт | Түвшин, Төрөл, Асуулт, A–D, Зөв хариулт, Алдааны хязгаар, Тайлбар, Зураг URL, Оноо |
| Дасгал | Түвшин, Хэсэг (Онол/Бодлого/Туршилт/Түвшний шалгалт), Хичээлийн гарчиг, … (дээрхтэй адил) |
| Хичээл | Түвшин, Хэсэг, Дараалал, Гарчиг, YouTube URL, Онол текст, Симуляц (pendulum/projectile/ohm) |
| Түвшин | Дугаар, Нэр, Тайлбар, Тэнцэх %, Icon, Өнгө |

Төрөл: `mcq` (A–D), `numeric` (тоо; алдааны хязгаар хоосон бол ±1%), `truefalse` (Үнэн/Худал).
Томьёо: `$F = ma$` эсвэл `$$...$$`. Импортоос өмнө мөр бүрийн алдааг харуулна. «Нэмэх» эсвэл «Солих» горимтой.
`physlab_sample.xlsx` — жишээ 3 түвшний бүтэн контент (`python sample_data.py`-ээр дахин гаргана).
